# 11. 위험요소 및 대응

## 원문 기준
| 위험 | 영향 | 대응 | 등급 |
|---|---|---|---|
| 범위 과대 | 모든 ERP 기능을 동시에 개발하면 일정·품질이 무너짐 | 모듈형 전체 설계는 유지하되 단계별 릴리스와 완료 게이트 적용 | 상 |
| AI 환각·오실행 | 잘못된 답변·금전·권한 변경 위험 | 근거 필수, 권한 선필터, 실행 미리보기, 승인, 도구 allowlist, 롤백 | 상 |
| 동아리 결제의사 낮음 | 무료 도구 대비 유료전환 어려움 | 교육 무료 요금제+조직 인수인계·회비·Agent를 핵심 가치로 검증 | 상 |
| 데이터 분산·품질 | 기존 메신저·문서·시트가 불완전 | 가져오기 매핑·품질리포트·출처·수동승인 제공 | 중 |
| 권한 복잡성 | 조직마다 역할이 다름 | 기본 템플릿+세부 정책+권한 시뮬레이션+자동 테스트 | 상 |
| LLM 비용·장애 | 사용량 증가·공급자 장애 | 모델 라우팅, 캐시, 쿼터, 로컬 모델, 폴백, 비용 대시보드 | 중 |
| 개인정보 | 회원·지원자·회계 정보 노출 | 최소수집, 필드권한, 마스킹, 보존정책, AI 데이터등급 | 상 |

## 구현 관점 추가 위험
| 위험 | 영향 | 대응 | 등급 |
|---|---|---|---|
| 테넌트 격리 누락 | 조직 간 데이터 유출 = 제품 신뢰 붕괴 | RLS + 애플리케이션 이중 검증 + 자동 cross-tenant 침투 테스트(DAR-001) | 상 |
| AI 도구 승인 우회 | 금전·권한 무단 변경 | 서버에서 도구 파라미터·권한 재검증, 실행토큰 단수명, 멱등키로 중복 실행 차단(TER-006) | 상 |
| 프롬프트 인젝션 | 권한확대·비밀노출 | untrusted 태그, allowlist, 출력 검증(SER-004) | 상 |
| 회계 합계 불일치 | 검수 실패 조건 | 원장·보고서·거래·예산 합계 대조 테스트를 CI 게이트에 포함 | 상 |
| 마감 기간 데이터 변조 | 회계 신뢰 붕괴 | fiscal_period_lock + 재오픈 승인 + 감사로그 | 상 |
| 감사로그 위변조 | 추적성 상실 | append-only + 해시체인 무결성 검증(DAR-007) | 상 |
| 검색 인덱스 권한 지연 | 권한 철회 문서 인용 | 이벤트 기반 동기화 + 검색 후 권한 재검증 | 상 |
| 53화면 상태 누락 | 검수 불합격 | 상태 체크리스트를 컴포넌트 테스트로 강제 | 중 |
| 파일 악성코드 | 조직 감염 | 업로드 스캔·격리·presigned 만료(SER-003) | 중 |
| 마이그레이션 부분 확정 | 데이터 오염 | dry-run + 트랜잭션 일괄 확정 + 롤백(DAR-009) | 중 |
| LLM 비용 폭증 | 운영비 리스크 | 조직·사용자 쿼터, 캐시, 로컬 모델 우선 라우팅, 비용 대시보드 | 중 |
| 범위 과대로 인한 미완성 | 납품 실패 | 모듈 단위 승인 진행 + 각 모듈 완료 게이트 | 상 |
