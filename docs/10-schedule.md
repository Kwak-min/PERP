| 3. 플랫폼 코어 | 9~14주 | 인증, 멀티테넌시, 회원, 권한, 공통 셸, 알림, 감사 | 테넌트·권한 테스트 통과 |
| 4. 운영 모듈 | 15~22주 | 프로젝트, 일정, 문서, 인수인계, 승인, 자산, 인사 | 모듈 통합 시연 통과 |

| 6. AI·자동화 | 28~32주 | RAG, 개인화, 기억, Agent 도구, 모델 라우팅, 자동화 | AI 평가·안전성 기준 통과 |
| 7. 통합·파일럿 | 33~35주 | 외부 연동, 데이터 이전, 파일럿 3개 조직, 개선 | 사용성·성능·보안 기준 통과 |
| 8. 배포·인수 | 36주 | 운영 배포, 교육, 문서, 소스·계정 인수 | 최종 검수 |

## 본 저장소 실행 모듈 (사용자 승인 단위)
| 모듈 | 대응 단계 | 산출물 | 완료 게이트 |
|---|---|---|---|
| M1 설계문서 | 2단계 | docs/ 12종 + 실행계획 | 커버리지 스크립트 MISSING 0 |
| M2 공통 플랫폼 | 3단계 | 인증·멀티테넌시·조직·회원·RBAC·앱셸·전역검색·알림·설정·감사로그 | 테넌트 격리 + 권한 테스트 통과 |
| M3 운영 모듈 | 4단계 | 프로젝트·업무·캘린더·문서·회의록·인수인계·결재 | 모듈 통합 E2E 통과 |
| M4 재무·자원·인사 | 5단계 | 회계·회비·예산·정산·자산·예약·인사·근태·휴가·모집 | 회계 합계 정합성 테스트 통과 |
| M5 AI Agent | 6단계 | Gateway·Adapter·권한RAG·브리핑·기억·역할Agent·도구실행·승인·롤백·평가 | AI 정확도 85%/근거 95%/무승인 실행 0건 |
| M6 자동화·연동·분석 | 6~7단계 | Workflow Builder·실행로그·캘린더/메신저/스토리지 연동·공개API·Webhook·KPI·보고서·내보내기 | 성능·보안·사용성 기준 통과 |

각 모듈 종료 시 보고 항목: 구현된 기능 / 변경된 파일 / DB 변경사항 / API 변경사항 / 권한 변경사항 / 테스트 결과 / 남은 문제 / 다음 구현 단계.
