## 라우트 가드 규칙

1. 미들웨어에서 세션 확인 → 없으면 `/login?next=`로 리다이렉트
2. 서버 컴포넌트/라우트 핸들러에서 `tenant_id` + membership 상태 재확인
3. 리소스 권한(resource/action/scope) 재확인 — 프론트 메뉴 숨김은 UX일 뿐 권한 구현이 아니다
4. 권한 거부 시 데이터 존재 여부를 노출하지 않는 403 화면 (필요 권한·요청 방법 안내)
