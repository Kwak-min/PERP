# 사용자 매뉴얼 (User Manual)

## 1. 시작하기
1. 초대 메일의 링크로 `/signup` 에서 가입하면 조직에 자동 합류된다.
2. 로그인 후 첫 화면은 **개인 대시보드**(`/`)다: 오늘 업무, 마감 임박, 지연, 오늘 일정, 승인 대기, 읽지 않은 공지, AI 브리핑.
3. 상단바에서 전역 검색(업무·프로젝트·문서·회원·일정·자산)과 빠른 생성을 사용한다. 권한 밖 결과는 존재조차 표시되지 않는다.

## 2. 업무
- `/tasks` 목록, `/projects/{id}/board` 칸반, `/projects/{id}/timeline` 간트, `/workload` 업무량.
- 하위 업무·의존성·체크리스트·댓글·멘션·반복을 지원한다.
- **필수 체크리스트가 남아있거나 선행 업무가 끝나지 않으면 완료로 전환되지 않는다.**

## 3. 일정
- `/calendar` 에서 개인·조직·프로젝트 일정을 함께 본다.
- 참석자가 겹치면 생성 시 충돌 경고가 표시되고, `GET /calendar/availability` 로 빈 시간을 추천받는다.
- 일정에서 회의록을 만들면 결정사항을 **확인한 항목만** 업무로 생성된다.

## 4. 문서·회의록
- `/documents` 공간·폴더·태그·버전. 저장할 때마다 버전이 쌓이고 특정 리비전으로 복원할 수 있다.
- `/documents/meetings/{id}` 회의록: 안건·논의·결정사항·담당자·기한. AI 요약에는 항상 근거 링크가 붙는다.

## 5. 개인 AI Agent
- `/agent` 채팅, `/agent/brief` 오늘의 브리핑, `/agent/memory` 기억 관리.
- 답변은 항상 **결론 / 근거 / 관련 데이터 / 불확실성 / 추천 다음 행동 / 실행 가능 여부 / 필요한 승인** 형식이다.
- 근거가 없으면 불확실성이 표시되며, AI는 승인 없이 데이터를 바꾸지 않는다.
- 기억은 언제든 조회·수정·삭제·전체 초기화할 수 있고, 삭제 즉시 답변에서 제외된다. 비밀번호·인증키·주민등록번호는 저장이 거부된다.

## 6. 개인 Vault (나만의 지식 노트)
- `/vault` 에서 개인 노트를 만들고 폴더·태그로 정리한다.
- 본문에 `[[다른 노트 제목]]` 을 쓰면 자동으로 링크되고, 대상 노트에 백링크가 생긴다.
- `/vault/graph` 에서 노트 연결 구조와 연결이 없는 노트(고아)를 확인한다.
- 노트마다 "Agent 사용" 을 켜고 끌 수 있다. 켜진 노트만 내 Agent 답변의 근거로 쓰인다.
- **Vault 는 나만 볼 수 있다.** 같은 조직의 관리자도 열람할 수 없다.

## 7. 회비·정산
- `/finance/dues` 에서 내 회비 청구·납부 상태를 본다(일반 구성원은 본인 내역만 보인다).
- `/finance/settlements` 에서 지출 요청 → 영수증 첨부 → 결재. AI가 추출한 금액·날짜·상호는 **원본과 함께 검토한 뒤** 확정된다.

## 8. 결재
- `/approvals` 받은/보낸/참조/완료 탭. 승인·반려·보류·위임·회수를 지원한다.
- 고액 결재는 승인 시 비밀번호 재인증을 요구한다.

## 9. 인수인계
- `/handover` 에서 인계 패키지를 만들고 "자료 수집"을 누르면 미완료 업무·반복 업무·핵심 문서·반복 일정이 자동 수집된다.
- 비밀번호 등 민감 정보는 자동으로 제외된다.
- 필수 항목을 모두 체크하고 전임·후임·관리자 3인이 확인해야 완료된다.

## 10. 화면 상태 안내
| 상태 | 표시 |
|---|---|
| 로딩 | 스켈레톤 |
| 빈 목록 | 왜 비었는지 + 첫 행동 버튼 |
| 오류 | 문제·원인·재시도·요청 ID |
| 권한 없음 | 필요 권한과 요청 방법 (데이터 존재 여부는 숨김) |
| 오프라인 | 마지막 동기화 시각 배너 |
| 미저장 | 이탈 경고 + 자동저장 상태 |
| AI 생성 | 보라색 AI 라벨 + 생성 시각 + 근거 + 검토 상태 + 수정/승인/폐기 |
