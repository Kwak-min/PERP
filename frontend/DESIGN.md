# OrbitFlow Design System

색상 팔레트는 기존 인디고/바이올렛을 유지하고, **형태 언어만** 재설계했다.
레퍼런스(엔터프라이즈 ERP 대시보드)에서 가져온 것은 구조·밀도·형태이며 색은 가져오지 않았다.

## 0. 설계 원칙

1. **뭉툭하고 각지게** — 반경 6~8px 고정. pill(999px) 금지.
2. **보더 우선, 그림자 최소** — 구획은 1px 보더로. 그림자는 떠 있는 표면(패널/드롭다운)만.
3. **밀도 우선** — 행 높이를 낮추고 여백을 조인다. 한 화면에서 더 많은 사실이 보여야 한다.
4. **카드마다 액션 슬롯** — 모든 섹션 카드 우상단에 `자세히` 액션. 데이터는 항상 다음 행동으로 이어진다.
5. **갱신 시각 표기** — 수치 카드는 언제 기준인지 밝힌다.

## 4. 레이아웃

- 앱 셸: 사이드바 236px(라이트) + 상단바 56px + 본문 max 1360px
- 대시보드형: KPI 4열 → 콘텐츠 12칼럼 그리드(8+4 / 4+4+4)
- 리스트형: 필터 바 → 밀도 테이블 → 행 액션
- 상세형: 본문 8칼럼 + 메타 레일 4칼럼

## 5. 상태 규칙

모든 화면은 로딩·빈·오류·권한거부·모바일 상태를 가진다.
서버 응답과 사용자가 선택한 실제 항목만 표시한다. 백엔드 오류는 오류 상태로, 빈 응답은 빈 상태로 표시하며 샘플 데이터로 대체하지 않는다. 부서·브랜치는 사용자가 명시적으로 추가한 항목만 생성한다.

역할 설정은 메뉴·업무 동작·위임을 별도 fieldset으로 묶고 명시적으로 저장한다. 저장 중 모든 편집 제어를 잠그고, 충돌 시 기존 카드/보조면 토큰으로 초안과 최신 저장값을 나란히 비교한다(모바일은 세로). 비교 확인은 저장이 아니며 초안과 서버 버전을 분리한다. 성공 상태는 접근 권한 갱신보다 먼저 표시하고, 권한을 잃으면 편집을 종료한다. 체크박스는 16px, 클릭 가능한 label은 최소 44px를 유지한다.

## 6. 접근성

- 포커스 링 2px `--of-primary`, offset 2px
- 상태를 색만으로 전달하지 않는다(텍스트/아이콘 병기)
- 조직도 연결선은 보고 관계를 보조하며, 각 노드의 부서명과 권한 텍스트를 함께 제공한다.
- 375 / 768 / 1280px 검증
- 최소 터치 타깃 44px (모바일)

## 재무 입력·원증빙

- 기존 Button, 보더 카드와 12px 간격을 재사용한다. 새 색상·동작 라이브러리는 추가하지 않는다. 재무 섹션 제목은 18px, 행 제목 15px, 금액 요약 24px를 사용한다. 요약 열은 최소 240px(화면보다 넓어지지 않음)로 재배치한다.
- ExpenseForm은 금액·사용처 → 날짜·선택 시각 → 계정·예산 → 메모 → 증빙 → 명시 확인 순서다. 2열 필드는 600px 이하에서 1열이 된다. 본문이 스크롤을 소유한다.
- ReceiptUploads는 대기/완료/실패/재시도/제거 상태를 텍스트로 알린다. 원본은 이름·형식·크기만 표시하고 다운로드만 제공한다.
- 전표 목록은 전체 조회 후 10건씩 표시한다. 수입·초안·과거 전표를 기본 필터에서 제외하지 않는다. 새 지출 성공은 확정 장부 기록이며, 금액 수정 버튼은 없다.
- 로딩·오류·확인·저장 중·응답 유실 재시도·상세·빈 상태를 375/768/1280px 실제 브라우저에서 검증한다. 금액과 파일명은 좁은 화면에서도 누락되지 않는다.

## CSV 가져오기 검토

- 흐름은 파일 선택 → 헤더 자동매핑 확인 → 샘플과 전체 행 오류/중복 페이지(25행) → 계정 매핑 명시 확인 → 적용이다. 모호한 계정은 사용자가 선택해야 하며 invalid 행이 있으면 적용 버튼을 활성화하지 않는다.
- 미리보기 수정은 항상 새 job이다. 화면은 job ID와 생성한 `Idempotency-Key`를 보존하고, 응답 유실 뒤에는 같은 key로 재시도하거나 job 상태를 조회한다. 행 데이터를 commit 본문에 다시 보내지 않는다.
- `content_expired:true`(24시간 만료)는 "만료되었습니다. 원본과 민감한 값을 폐기했습니다. 파일을 다시 선택해 새 검토를 시작하세요." 안내 상태로 표시하고 캐시한 원본을 폐기한다. 만료는 오류가 아니라 정상 상태다.
- summary의 amount는 "선택 미리보기 합계 … KRW (아직 장부 지출 아님)"처럼 확정 장부 금액과 구분해 표기한다. 적용 완료 뒤에만 "완료 합계"와 created/reused 건수를 보인다.

## 결재

- 상태는 draft/pending/approved/rejected/withdrawn(PG)과 legacy hold를 텍스트 배지로 구분한다. 종결 원본은 읽기 전용이며 "재상신"은 원본에 연결된 새 draft를 만든다는 문구를 그대로 쓴다.
- 반려는 사유 입력이 비어 있으면 제출할 수 없다. 본인 요청 결정은 명시 확인 체크를 요구한다.
- 첨부는 이름·형식·크기와 다운로드만 제공한다. 제출 뒤 잠긴 첨부에는 추가·교체·삭제 버튼을 렌더하지 않는다.
- legacy(배정된 순차 결재 단계)와 PG(회사 결정자 pool)의 "내가 결정할 수 있는 요청" 정의가 다르다. 결정 불가 문구는 저장소 기준("배정된 단계가 아닙니다" / 결정자 pool 아님)을 구분해 보이고, 두 기준을 하나로 뭉개지 않는다.

## 분석

- 카드는 서버가 준 `state`를 상태 라벨로 그대로 표현한다. ready "조회 완료", empty "데이터 없음", forbidden "원천 권한 없음", disabled "기능 꺼짐", unavailable은 라벨과 함께 `reason` 설명(`SOURCE_UNSUPPORTED`, `MIXED_CURRENCY` 등)을 텍스트와 코드로 보인다. 어떤 상태도 0이나 대시로 대체하지 않는다.
- 금액은 서버 문자열과 `unit`을 그대로 표시한다. PG는 `ledger_decimal`, legacy는 실제 통화다. '원'을 하드코딩하지 않는다.
- `series`가 비어 있으면 추세 화살표·스파크라인을 그리지 않는다. 기준 라벨은 current_snapshot "현재 상태 (과거 말일 상태 아님)", period_flow "선택 기간 흐름 [시작, 종료)"처럼 basis 코드와 함께 표기한다.
- export 영역은 "다운로드할 때 저장된 필터와 현재 권한으로 원천 데이터를 다시 조회합니다"를 안내하고, 413은 기간을 좁히라는 문구로 표시한다. 5,000행 절단 같은 조용한 축소는 없다.

## 지식 그래프·LLM Wiki

- 개인 Vault와 회사 문서 그래프는 같은 `KnowledgeGraphStage`(pinned `3d-force-graph@1.80.0`, `three@0.185.1`)와 legend·필터·색 규칙을 공유한다. 조직도·결재 diagram은 force graph로 바꾸지 않는다.
- 관계는 citation(directed), manual, ai_derived, ai_similarity, space/membership을 서로 다른 시각 규칙과 provenance로 구분한다. parallel edge와 방향을 합치지 않으며 AI 파생 근거를 AI 유사도로 표시하지 않는다.
- WebGL 불가·엔진 import 실패·context loss는 정직한 오류 문구와 키보드 semantic 목록으로 대체한다. `prefers-reduced-motion`이면 autorotate·layout animation·camera tween을 끈다. route unmount 때 renderer/RAF/listener/objectURL을 정리한다.
- 레이아웃·camera는 reload 시 초기화되는 기본 계약이고, 내용·링크만 서버가 유지한다. "모든 링크가 영구 저장"이라고 쓰지 않는다.
- Wiki 화면은 원본 → 검토 전 조사 → 초안 검토 → 명시적 게시 순서를 상단에 고정 문구로 보인다. 결과에는 "검토 전 모델 생성 결과"와 인용 상태(`인용 위치 확인됨 · 사실 검증 아님` / `근거 없음`)를 함께 표시한다.
- job 상태는 접수됨/조사 중/완료·검토 전/실패/사용 불가로 표시한다. 모델 부재의 "사용 불가"는 답변이나 게시물이 아니며 게시된 위키 읽기와 원본 등록은 계속 가능하다는 문구를 유지한다.
- 게시 버튼은 서버 digest를 사용자가 확인(체크)하고 freshness가 `current`일 때만 활성화한다. 초안은 일반 목록·그래프에 나오지 않고 검토 영역에만 보인다. `stale`/`unavailable`(`SOURCE_REVOKED`)은 배지 텍스트로 구분한다.
- PG 개인 Vault 소유자는 회사 선택과 무관한 인증 사용자다. 회사 전환 시 진행 중 요청을 abort하고 이전 scope 응답을 폐기하되, 개인 노트 소유자를 회사로 바꾸지 않는다.

## 7. 수용된 부채

- 차트는 CSS/SVG 자체 구현(경량 스파크라인·도넛). 차트 라이브러리 미도입. 3D 엔진은 지식 그래프·Wiki 그래프에만 사용한다.
- 사이드바 아이콘은 텍스트 마크로 대체(아이콘셋 미도입).
- 접기/즐겨찾기 상태는 사용자·회사별 localStorage(버전 1)에만 저장한다. 서버 동기화는 없으며 화면에 "이 브라우저에만 저장"을 표시한다.
