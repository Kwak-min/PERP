# OrbitFlow Design System

색상 팔레트는 기존 인디고/바이올렛을 유지하고, **형태 언어만** 재설계했다.
레퍼런스(엔터프라이즈 ERP 대시보드)에서 가져온 것은 구조·밀도·형태이며 색은 가져오지 않았다.

## 0. 설계 원칙

1. **뭉툭하고 각지게** — 반경 6~8px 고정. pill(999px) 금지.
2. **보더 우선, 그림자 최소** — 구획은 1px 보더로. 그림자는 떠 있는 표면(패널/드롭다운)만.
3. **밀도 우선** — 행 높이를 낮추고 여백을 조인다. 한 화면에서 더 많은 사실이 보여야 한다.
4. **카드마다 액션 슬롯** — 모든 섹션 카드 우상단에 `자세히` 액션. 데이터는 항상 다음 행동으로 이어진다.
5. **갱신 시각 표기** — 수치 카드는 언제 기준인지 밝힌다.

## 1. 토큰

| 목적 | 토큰 | 값 |
|---|---|---|
| 주요 액션 / 포커스 | `--of-primary` | `#4f46e5` |
| AI 표면 | `--of-ai` | `#7c3aed` |
| 성공 / 경고 / 위험 | `--of-success` `--of-warning` `--of-danger` | `#15803d` `#b45309` `#b91c1c` |
| 캔버스 / 카드 / 보조면 | `--of-surface` `--of-card` `--of-surface-muted` | `#f5f7fa` `#ffffff` `#f1f5f9` |
| 보더 / 강한 보더 | `--of-border` `--of-border-strong` | `#e2e8f0` `#cbd5e1` |
| 본문 / 보조 텍스트 | `--of-text` `--of-text-muted` | `#0f172a` `#5b6b80` |
| 사이드바(라이트) | `--of-sidebar` `--of-sidebar-border` | `#ffffff` `#e2e8f0` |

반경: `--r-sm 4px` / `--r-md 6px` / `--r-lg 8px` — 이 셋만 사용한다.
간격: 4의 배수. 카드 내부 패딩 16px, 그리드 간격 12px.

## 2. 타이포

Pretendard → Noto Sans KR → system-ui.
- 화면 제목 24px / 자간 -0.02em
- 카드 제목 13px 대문자 자간 0.04em (섹션 캡션)
- 수치 28px 800
- 본문 13px, 표 12.5px, 캡션 11px

## 3. 프리미티브

| 이름 | 용도 | 상태 |
|---|---|---|
| `Button` | primary / neutral / ai / danger, small·medium | hover, disabled, focus-visible |
| `Badge` | 상태·모듈 라벨. 사각 4px | neutral/success/warning/danger/ai |
| `StatCard` | 라벨 → 수치 → 델타 → 갱신시각, 우상단 액션 | 상승/하락/중립 |
| `SectionCard` | 제목 + 부제 + 우상단 액션 슬롯 + 본문 | — |
| `ListRow` | 좌측 마크 + 2줄(제목/부제) + 우측 메타·액션 | hover |
| `DataTable` | 낮은 행 높이, 헤더 대문자, 가로 스크롤 | 빈 상태 |

## 4. 레이아웃

- 앱 셸: 사이드바 236px(라이트) + 상단바 56px + 본문 max 1360px
- 대시보드형: KPI 4열 → 콘텐츠 12칼럼 그리드(8+4 / 4+4+4)
- 리스트형: 필터 바 → 밀도 테이블 → 행 액션
- 상세형: 본문 8칼럼 + 메타 레일 4칼럼

## 5. 상태 규칙

모든 화면은 로딩·빈·오류·권한거부·모바일 상태를 가진다.
백엔드가 없거나 엔드포인트가 비어 있으면 화면별 시드 픽스처로 폴백하고, 상단에 `데모 데이터` 배지를 표시한다.

## 6. 접근성

- 포커스 링 2px `--of-primary`, offset 2px
- 상태를 색만으로 전달하지 않는다(텍스트/아이콘 병기)
- 375 / 768 / 1280px 검증
- 최소 터치 타깃 44px (모바일)

## 7. 수용된 부채

- 차트는 CSS/SVG 자체 구현(경량 스파크라인·도넛). 차트 라이브러리 미도입.
- 사이드바 아이콘은 텍스트 마크로 대체(아이콘셋 미도입).
